*Extremal relations and Betti numbers of four-generated numerical semigroups* (version 4, 19 November 2026). No journal has been selected. The preprint and the software are separate scholarly outputs; version-specific Zenodo identifiers are listed below. The earlier software DOI [10.5281/zenodo.23549534](https://doi.org/10.5281/zenodo.23549534) is historical and predates the present Betti extension.

For numerical semigroups minimally generated by four integers, with multiplicity m ≥ 4, the maximum minimal-presentation cardinality is T(m) = 2 + floor(2 sqrt(m)), and it is attained. The development also proves the complete attainable presentation-size spectrum and the embedding-dimension-four Macaulay equality range 4 ≤ m ≤ 9.

The new public entry point [P3Betti.lean](P3Betti.lean) defines total Betti numbers using Mathlib's actual categorical Tor. For every field with carrier `Type` (universe 0), the formalization proves finiteness, (β₀, β₁, β₂, β₃) = (1, η, η + τ − 1, τ), vanishing in degrees ≥ 4, and independence of the field and its characteristic. It proves β₁ ≤ T, β₂ ≤ 2T − 2, β₃ ≤ T − 1, with improvements under the stated no-full-support hypothesis. Known families realize (1, q, 2q − 4, q − 3). The attained maxima lie in 2T − 4 ≤ max β₂ ≤ 2T − 2 and T − 3 ≤ max β₃ ≤ T − 1. **The exact maxima and classification of all Betti tuples are not determined.**

## Reproduce

The exact Lean toolchain and nine dependency Git revisions are in `lean-toolchain` and `lake-manifest.json`. Dependencies and build products are not vendored. After installing the specified toolchain:

```sh
python -B tools/verify_publication.py
python -B -O tools/verify_publication.py
lake exe cache get
lake build P3Betti P3TorSpike
lake build NSP3
lake env lean P3TorSpike/FinalChecks.lean
python -B verification/verify_revision.py --source manuscript/P3_PREPRINT.tex
```

`lake exe cache get` retrieves Mathlib dependency caches. The Lake commands above are reproduction instructions; this publication operation does not claim to have completed a clean full-tree Lake build. The finite Python checks are supplementary computations, not proofs of the infinite theorem. They require the explicit `--source` path because the original scripts' default filename refers to a historical manuscript.

The frozen [Tor completion ZIP](https://github.com/stksk310/NS-P3-Lean/releases/download/v0.2.0/NS_P3_TOR_BETTI_COMPLETION_20261116.zip) supplies the original source/receipt manifest, logs, and a replay runner. Its evidence records 52 newly checked Lean files, 523 preserved baseline files, and 17 principal axiom closures containing only `propext`, `Classical.choice`, and `Quot.sound`. These are **same-host executions using a matching-source previously built V03 baseline and cached dependencies**, not a dependency-cold, full-baseline, or independent-host replay. See [reproduction and evidence details](docs/REPRODUCIBILITY.md).

The preprint PDF was rebuilt from a fresh extraction of its source ZIP and checked for page count, references, embedded fonts, and layout. The separate AI editorial review concerns the source and disclosure, and is not human peer review or a new mathematical audit.
