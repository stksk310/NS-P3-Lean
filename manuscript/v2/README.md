# Preprint version 2

*Extremal relations and Betti numbers of four-generated numerical semigroups*,
Keisuke Sato, 19 November 2026.

- [Read the 26-page preprint](P3_EDITORIAL_R05.pdf)
- [LaTeX source](P3_EDITORIAL_R05.tex)
- [Manuscript, Lean interfaces, and verification records](P3_EDITORIAL_R05.zip)

This version revises the exposition, states the Lean definitions underlying
the extremal presentation theorem, and includes the completed source-build
records for the 269 project modules required by the paper checks. The
build used Lean 4.34.0-rc1 and pinned external dependency artifacts.
The appendix module was checked separately against those build outputs.
